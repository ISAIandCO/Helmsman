# Helmsman

VPN и виртуальные сети для Steam Deck: полная настройка в Desktop Mode и быстрые действия в боковом меню Decky Loader. Закрытие окна и переход между режимами не отключают соединение.

**Первая версия — предварительная.** Сетевые движки настоящие, конфигурации не имитируются. Проверки на Linux и испытания на физическом Steam Deck перечислены отдельно в [журнале проверки](docs/TESTING.md). Для подключения нужен ваш сервер, готовый профиль или подписка; Helmsman не продаёт VPN.

[Скачать релиз](https://github.com/ISAIandCO/Helmsman/releases) · [Сборки](https://github.com/ISAIandCO/Helmsman/actions) · [Сообщить о проблеме](https://github.com/ISAIandCO/Helmsman/issues)

## Что умеет

- VLESS, в том числе REALITY и Vision; Hysteria2 и отдельные профили Hysteria1; Shadowsocks, Trojan, VMess, TUIC, AnyTLS, SOCKS5 и HTTP(S).
- WireGuard, AmneziaWG и OpenVPN через общий механизм маршрутизации. Для Amnezia важен протокол внутри экспорта, а не название приложения.
- Подключение к сети ZeroTier с Node ID, адресами и состоянием ожидания авторизации.
- Импорт ссылок, подписок со списком ссылок или Base64, sing-box JSON, WG/AWG `.conf`, автономных OpenVPN `.ovpn` и поддерживаемых клиентских экспортов Amnezia `vpn://`.
- Общий или отдельный HWID для каждой подписки, ручные и автоматические обновления. При ошибке предыдущие профили остаются; обновление не перезапускает работающий туннель.
- Системный TUN для игр и программ без поддержки прокси. Правила по доменам, IP/CIDR, спискам, портам и Linux-процессам; действия «VPN», «напрямую», «блокировать».
- Сценарии полного и выборочного туннеля, доступ к LAN/Remote Play, IPv4/IPv6, настройка DNS и MTU, защита от прямого выхода при аварии.

Подробные форматы и ограничения — в [матрице совместимости](docs/COMPATIBILITY.md). Одновременно активно **одно** подключение. Произвольные цепочки и параллельные туннели разных движков не поддерживаются.

## Установка на SteamOS

1. Перейдите в Desktop Mode. Если пароль пользователя ещё не задан, выполните `passwd` в Konsole.
2. Скачайте `helmsman-<версия>-linux-x86_64.tar.gz` и `SHA256SUMS` из одного релиза. Архив содержит приложение, сервис и все сетевые движки. Decky Loader устанавливается отдельно с [официального сайта](https://decky.xyz/).
3. В каталоге загрузки проверьте контрольную сумму нужного архива, распакуйте и установите. Для версии `0.1.0-alpha.1`:

```bash
sha256sum --ignore-missing -c SHA256SUMS
tar -xzf helmsman-0.1.0-alpha.1-linux-x86_64.tar.gz
cd helmsman-0.1.0-alpha.1
sudo bash install.sh --decky
```

Без Decky используйте `sudo bash install.sh`. Плагин можно добавить позже повторным запуском с `--decky`. Для другого пользователя: `--user имя`.

4. Откройте **Helmsman** в меню приложений → Интернет. Плагин появится в боковом меню Decky. При необходимости перезапустите Decky Loader.

Установщик использует стандартные `systemd`, `iproute2`, `nftables`, `setpriv`, Python 3 и `/dev/net/tun`. Qt и Python для самого приложения включены в пакет. Не требуется отключать защиту системного образа SteamOS, устанавливать пакеты через pacman или запускать GUI от root. На другой Linux-системе перечисленные системные инструменты нужно установить штатным способом.

Файлы программы принадлежат root и находятся в `/var/lib/helmsman-app`, настройки — в `/var/lib/helmsman`. Службы добавляются в `/etc/systemd/system`. Эти данные вынесены за пределы `/usr`. После обновления SteamOS проверьте работу службы; если система убрала её регистрацию, повторите установку. Для восстановления системы с очисткой диска нужна отдельная резервная копия настроек.

## Первое подключение

1. Откройте **Профили → Импорт** и вставьте ссылку/конфигурацию либо откройте файл. Для ZeroTier есть отдельная кнопка добавления Network ID.
2. На вкладке **Подключение** выберите профиль и сценарий. По умолчанию весь интернет идёт через VPN, локальная сеть доступна напрямую.
3. Нажмите **Подключить**, затем **Проверить доступ через VPN**. Проверка устанавливает соединение с Steam Store через выбранный профиль с проверкой TLS. Это проверка DNS/TCP/TLS, а не измерение задержки в игре и не проверка всех UDP-приложений.

Статус «VPN включён» означает, что движок и TUN работают. Успех обращения к серверу показывается отдельно по результату проверки. Неверный ключ может не завершить сам процесс движка.

## Подписка с HWID

В **Подписки → Добавить** укажите HTTPS URL и период обновления. `0` означает только ручное обновление. После сохранения нажмите **Обновить все подписки**.

HWID создаётся случайным образом один раз и хранится в настройках. Серийные номера и сведения о железе не собираются. Можно заменить общий HWID, сгенерировать новый или задать свой только для одной подписки.

Выберите способ, который требует ваш сервис:

| Режим | Что отправляется |
|---|---|
| Не передавать | Запрос без HWID |
| Remnawave | `x-hwid`, `x-device-os: Linux`, `x-device-model: Steam Deck`, `x-ver-os: SteamOS` |
| HTTP-заголовок | Указанное вами имя заголовка и HWID |
| Параметр URL | Указанное вами имя query-параметра и HWID |

Для дополнительных требований есть поля HTTP-заголовков, например для `Authorization` или нужного `User-Agent`. Данные не записываются в диагностический журнал. Перенаправление на другой сервер или с HTTPS на HTTP отклоняется: укажите конечный доверенный URL. В режиме Remnawave HWID должен соответствовать ограничению панели: 10–64 латинских букв, цифр, `=` или `-`.

Обновление проверяет все полученные профили перед заменой. HTML вместо подписки, неподдерживаемый профиль или ошибка сети сохраняют предыдущую версию целиком. Переименованные узлы сохраняют ID, одинаковые соединения объединяются. Если выбранный узел исчез из подписки, он сохраняется отдельным профилем. Изменение импортированного узла вручную делает его самостоятельным профилем.

## Маршрутизация

| Сценарий | Через VPN | Напрямую |
|---|---|---|
| Весь интернет через VPN | Всё, кроме пользовательских исключений и разрешённой LAN | LAN и ваши прямые правила |
| Россия: выборочно | Домены и IP из общественных списков `ru-blocked` / `ru-ip-blocked`, ваши VPN-правила | Остальной трафик |
| Россия напрямую | Всё остальное | Категория российских доменов / российские IP, LAN и ваши исключения |
| Мои правила | По вашим правилам и выбранному маршруту по умолчанию | По вашим правилам |

Российские данные загружаются из [runetfreedom/russia-v2ray-rules-dat](https://github.com/runetfreedom/russia-v2ray-rules-dat). Это общественная подборка, **не гарантия фактической блокировки или доступности**. География IP и категория домена тоже не определяют владельца или юридический статус сервиса. Источник и дата доступны в конфигурации; во вкладке «Списки» видны дата и результат обновления. Неиспользуемые встроенные списки заранее не скачиваются.

Вкладка **Правила** задаёт порядок сверху вниз: первое совпавшее правило определяет действие. Пользовательские правила применяются перед правилами сценария. Сменить порядок можно перетаскиванием или кнопками, затем нажать «Применить порядок». Смена пресета ваши правила не удаляет.

DNS перехватывается TUN. Для доменной маршрутизации используется FakeIP; для IP/CIDR перед проверкой адресных правил выполняется разрешение настоящего адреса. Обычный DNS идёт через выбранное подключение; для явных прямых доменных правил — напрямую по DoH. Начальное разрешение адреса самого VPN-сервера использует прямой UDP DNS. В выборочном российском режиме не охваченные правилами запросы разрешаются прямо. DNS-серверы задаются в настройках; WG/AWG-профиль может задать внутренний DNS по IP. Собственный DoH внутри игры/браузера не раскрывает домен системному DNS: для таких программ используйте также IP-правила или полный туннель.

При включённом IPv6 перехватываются обе семьи адресов. Если его выключить, IPv6-трафик внутри маршрутизации отклоняется. Сервер и профиль тоже должны поддерживать IPv6 — Helmsman не добавляет его серверу автоматически.

LAN и служебный DNS обрабатываются раньше пользовательских правил. Опция LAN разрешает частные/link-local адреса и multicast, включая Remote Play и локальный поиск устройств. Для запрета доступа к LAN отключите эту опцию. На пересекающихся адресных диапазонах предпочтение имеют системные локальные маршруты; смените подсеть виртуальной сети, если она совпала с домашней.

В **Списки** можно импортировать текстовые домены/CIDR, sing-box source JSON или SRS по HTTPS. После добавления скопируйте ID списка и используйте его в правиле. Обновления идут автоматически (по умолчанию раз в 24 часа) или вручную; неудачная загрузка сохраняет старую версию. Пользовательский список можно изменить кнопкой «Изменить»: отредактировать URL/формат либо локальное содержимое. Для изменения встроенного списка создайте свою копию и замените ID в правиле.

Правила имён и путей процессов использует sing-box на Linux. Для Proton, Steam Linux Runtime и контейнеров имя может принадлежать `wine`, `pressure-vessel` или родительскому процессу, а не игре. Надёжная привязка к Steam App ID не заявляется. Для игрового сценария используйте домены/IP серверов, отдельный пресет или полный туннель. При переключении сценария открытые соединения перезапускаются.

## Decky Loader / Game Mode

В боковом меню **Helmsman** доступны подключение/отключение, выбор профиля, смена сценария, обновление подписок и проверка VPN. Используются стандартные элементы Decky с фокусом для кнопок и стиков. Полная настройка и ввод длинных ссылок доступны в Desktop Mode. В Desktop GUI работают мышь, сенсорный ввод и стандартная экранная клавиатура Steam (`Steam + X`).

GUI и плагин показывают состояние одной службы. Сами они не запускают сетевые движки и не удерживают соединение открытым. Настройки автоподключения фактически повторяют последнее намерение: включённое соединение восстанавливается после перезапуска службы/устройства; явное отключение это намерение отменяет.

## ZeroTier

Добавьте Network ID, выберите профиль и подключитесь. Если сеть закрытая, Helmsman покажет **Node ID** и сообщение о необходимости разрешить устройство в ZeroTier Central. Статус `REQUESTING_CONFIGURATION` означает ожидание контроллера, `ACCESS_DENIED` — ожидание разрешения, `NOT_FOUND` — неверный/несуществующий Network ID.

Это отдельный режим виртуальной LAN для совместной игры и доступа к устройствам. Обычный интернет остаётся прямым; пресеты интернет-VPN здесь не применяются. Глобальные/default-маршруты и DNS от контроллера запрещены. Разрешены только управляемые частные адреса/маршруты. VPN и ZeroTier одновременно не включаются. SSO-сети в этой сборке агента не поддерживаются.

## Обрыв, сон и смена сети

По умолчанию при включённом VPN устанавливается защитное правило nftables. Если процесс погибнет, системный трафик не получает прямой выход в интернет; доступ к разрешённой LAN и DHCP/IPv6 neighbor discovery сохраняется. Уже открытые прямые физические соединения также блокируются. Нельзя использовать другие VPN параллельно: их интерфейсы не получают автоматическое исключение.

При аварии защита блокирует **весь внешний трафик**, в том числе который обычно шёл прямо по выборочному пресету. Во время работы движка разрешённые прямые правила обслуживает сам движок. Это консервативная политика восстановления. Она не защищает от привилегированного администратора, который меняет firewall/маршруты, от сбоя ядра или от загрузки другой ОС.

Сервис отслеживает физические маршруты и большой промежуток после сна, восстанавливает выбранный механизм с ограниченным периодом повторов. Защита остаётся на время восстановления и перезапуска службы. Ранний boot-сервис ставит её перед NetworkManager после перезагрузки, если подключение ранее было включено. Поведение загрузки и сна требует проверки на конкретной версии SteamOS.

**Кнопка «Отключить» намеренно снимает защиту и восстанавливает обычный интернет.** Её же используйте, если для входа в публичный Wi-Fi нужен captive portal. Опцию блокировки можно отключить в настройках, тогда при аварии движка возможен прямой выход — это осознанный выбор.

Для UDP-игр предпочтителен протокол с нативной поддержкой UDP. HTTP-прокси не передаёт произвольный UDP; OpenVPN TCP и UDP-over-TCP могут ухудшать задержку при потерях. Начальный MTU TUN — 1400, WG/AWG — 1280, если в профиле не задан другой. При зависающих загрузках/голосе попробуйте MTU 1280–1380. Обход ограничений не гарантирует снижение пинга, доступность античита или конкретной игры.

## Обновление и удаление

Распакуйте новую версию и запустите тот же `install.sh`. Настройки и HWID сохраняются. Установщик переключает каталог версии, перезапускает службу и при ошибке её запуска возвращает предыдущий каталог. Предыдущие каталоги автоматически не удаляются; после успешной проверки их можно удалить вручную из `/var/lib/helmsman-app/versions`.

```bash
sudo bash uninstall.sh          # удалить программу и плагин, сохранить настройки
sudo bash uninstall.sh --purge  # также удалить профили, HWID и ключи
```

Для резервной копии сохраните `/var/lib/helmsman` с правами root. Архив содержит ключи и приватные URL; храните его как секрет. Копировать лучше после явного отключения и остановки службы, затем запустить её снова.

## Если что-то не работает

- **Нет связи с сервисом:** `systemctl status helmsman` и `journalctl -u helmsman -b`. Повторите установку после обновления SteamOS.
- **Сеть заблокирована после сбоя:** откройте Helmsman и нажмите «Отключить» либо выполните `sudo /var/lib/helmsman-app/current/Helmsman ctl disconnect`. Удаление также очищает ресурсы. Если повреждён сам сервис, используйте `uninstall.sh` — он выполняет независимую очистку только ресурсов Helmsman.
- **VPN включён, но сайт/игра не работают:** запустите проверку, проверьте сервер и время устройства, формат профиля, UDP у провайдера и MTU. Статус процесса не равен успешному удалённому handshake.
- **Не обновляется подписка:** проверьте режим HWID, конечный HTTPS URL, сертификат и формат ответа. Clash YAML, административные ключи Amnezia и конфигурации со сторонними скриптами нужно экспортировать в поддерживаемый формат.
- **Не подходит профиль VLESS:** XHTTP, новый VLESS encryption и специфические расширения Xray в этой версии не поддерживаются. TCP/WS/gRPC/HTTPUpgrade с TLS/REALITY — отдельные варианты; параметры должны совпадать с сервером.
- **Не виден Decky-плагин:** сначала установите Decky, затем повторите установку Helmsman с `--decky`. Архив плагина сам по себе не содержит системный сервис.
- **Не работает локальное устройство:** включите LAN и проверьте пересечения подсетей; для ZeroTier проверьте разрешение Node ID и настройки сети.

Диагностика приложения содержит состояния и безопасные сообщения. URL подписок, HWID и конфигурации в обычный журнал не выводятся. Перед публикацией собственных файлов/скриншотов проверьте, что в них нет ключей.
