Helmsman 0.1.0-alpha.5 для Steam Deck.

- Обновление подписок и HWID сверены с NekoBox_SF. Добавлены параметры hwid=…,os=…,osVersion=…,model=… с той же семантикой: заполненный список передаёт только перечисленные поля. Обычный HWID, общий идентификатор и ручные header/query-режимы сохранены.
- User-Agent настраивается для каждой подписки; по умолчанию используется совместимый V2Ray URI/Base64, доступны sing-box JSON и ручной ввод. Дополнительные HTTP-заголовки применяются последними без учёта регистра имени.
- Подписка обновляется сразу после сохранения; можно отдельно обновить выбранную. Desktop, Decky и расписание используют одни параметры.
- Исправлен импорт VLESS URI с headerType=none/packetEncoding и массивов полных конфигураций. Клиентский Xray JSON поддерживает TCP/raw, WS, gRPC, HTTP/HTTPUpgrade и XHTTP; системные правила и серверные компоненты не импортируются.
- Добавлены gzip с ограничением распаковки и понятные сообщения об отказе по HWID, лимите устройств, пустой подписке и веб-странице вместо профилей. Ошибка обновления сохраняет прежние профили, выбранное подключение и HWID.

Установка/обновление: распакуйте полный linux-x86_64.tar.gz и выполните sudo bash install.sh --decky. Программа и состояние остаются в /opt/helmsman. Сохранены исправления установки/удаления плагина в защищённом каталоге Decky.

Для переноса настройки NekoBox_SF: Подписки → Изменить → HWID / NekoBox_SF / Remnawave → вставить строку в параметры HWID и при необходимости изменить User-Agent → Сохранить и обновить. Если сервер выдаёт Clash YAML, выберите V2Ray URI/Base64 или sing-box JSON.

Запросы проверяются настоящим HTTPS fixture в CI; личная подписка VLESS+, внешние провайдеры и физический Steam Deck требуют проверки пользователем. Конкретный URL/ответ провайдера не предоставлен, поэтому успешное обновление именно этой подписки не заявляется.
