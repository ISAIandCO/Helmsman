Helmsman 0.1.0-alpha.11 для Steam Deck.

- Исправлен путь подписок по образцу NekoBox_SF: по умолчанию запрашивается Clash Meta; добавлен импорт YAML/JSON proxies с отдельными VLESS/REALITY и Hysteria2, включая Salamander, скорости и hopping. Сохраняются URI/Base64, sing-box и Xray JSON.
- Прежний автоматически заданный Helmsman User-Agent заменяется при запросе. Пользовательские User-Agent, HWID и дополнительные заголовки сохраняются. Desktop и Decky обновляют одну подписку через общий сервис.
- Поддержан VLESS XHTTP из Clash Meta. Расширен нативный TLS/REALITY-импорт: штатные клиентские TLS-настройки, встроенные CA, SHA256 pin и пустые экспортируемые поля. Параметры применяются движками, а не просто пропускаются парсером.
- Неудачное обновление сохраняет прежние профили и настройки. Чужие DNS/маршруты/TUN, внешние proxy-providers, скрипты и файловые ключи не применяются. Подробные ограничения — docs/COMPATIBILITY.md.

Обновление: распаковать helmsman-0.1.0-alpha.11-linux-x86_64.tar.gz, выполнить sudo bash install.sh --decky, повторить обновление подписки. Конфигурация и HWID сохраняются.

Проверки используют локальные серверы и GitHub CI. Личная подписка пользователя, доступность его провайдера и физический Steam Deck требуют проверки на устройстве.
