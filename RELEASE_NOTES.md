Первый стабильный выпуск Helmsman для Steam Deck: VPN на рабочем столе и в боковом меню Decky Loader.

## Возможности

- VLESS с REALITY и XHTTP, Hysteria2, WireGuard/AmneziaWG, OpenVPN, Shadowsocks, Trojan, VMess и другие протоколы.
- Подписки с HWID и параметрами устройства как в NekoBox_SF, обновление вручную или по расписанию с сохранением прежних профилей при ошибке.
- Полный туннель, российские сценарии, свои правила «VPN / напрямую / блокировать», отдельные DoH/DoT для VPN и прямых запросов.
- Импорт и создание WARP, в том числе с маскировкой AmneziaWG; подключение к виртуальной LAN ZeroTier.
- Общий фоновый сервис для Desktop и Decky, защита при сбое и опциональное автоподключение. Закрытие окна и переход между режимами сохраняют соединение.

## Установка

1. Перейдите в Desktop Mode. Если пароль пользователя ещё не задан, выполните `passwd` в Konsole. Для Game Mode предварительно установите [Decky Loader](https://decky.xyz/).
2. Скачайте из Assets **`helmsman-1.0.0-linux-x86_64.tar.gz`** и `SHA256SUMS`. Откройте терминал в папке загрузки:

```bash
sha256sum --ignore-missing -c SHA256SUMS
tar -xzf helmsman-1.0.0-linux-x86_64.tar.gz
cd helmsman-1.0.0
sudo bash ./install.sh --decky
```

Без Decky выполните `sudo bash ./install.sh`. Приложение и движки устанавливаются в **`/opt/helmsman`**. **Отключать read-only режим SteamOS не требуется.** Отдельная установка движков или ZIP плагина не нужна.

3. Откройте **Helmsman** в меню KDE → Интернет. В **Подписки → Добавить** вставьте ссылку и настройте HWID при необходимости, затем нажмите **Сохранить и обновить**. Либо импортируйте готовый профиль через **Профили → Добавить**.
4. В **Подключении** выберите профиль и маршрут, нажмите **Подключить → Проверить подключение**. В Game Mode управление доступно через **… → Decky → Helmsman**.

**Обновление с alpha.3 и новее:** та же команда установки сохраняет профили, HWID, правила и аккаунт WARP. После установки заново откройте окно приложения. Удаление — `sudo bash ./uninstall.sh`; настройки сохраняются, если не добавлен `--purge`.

**Ограничения:** одно выбранное подключение; ZeroTier работает отдельно от интернет-VPN. Сочетания протоколов и форматов описаны в [матрице совместимости](https://github.com/ISAIandCO/Helmsman/blob/v1.0.0/docs/COMPATIBILITY.md). Автоматические Linux-проверки не заменяют испытания конкретного сервера, игры и сна на Steam Deck.
