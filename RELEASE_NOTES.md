Helmsman 0.1.0-alpha.4 для Steam Deck.

- Исправлена ошибка Permission denied при установке Decky-плагина в защищённый homebrew/plugins. Установщик копирует только свой плагин с правами root; сам backend плагина продолжает работать без root. Менять владельца всего каталога Decky не требуется.
- Исправлено удаление плагина из защищённого каталога. Соседние плагины не изменяются.
- Установка/обновление/удаление с --decky теперь проверяются в CI с root-owned каталогом plugins, недоступным для записи обычному пользователю.
- Программа и настройки остаются в /opt/helmsman; профили, HWID и аккаунт WARP сохраняются при обновлении с alpha.3. Сохранены XHTTP, WARP/AmneziaWG, генератор Desktop/Decky и раздельные пользовательские DoH/DoT.

Скачайте linux-x86_64.tar.gz и SHA256SUMS, проверьте сумму, распакуйте архив и выполните sudo bash install.sh --decky. Без Decky — sudo bash install.sh. Откройте Helmsman в меню приложений → Интернет.

Физический Steam Deck, работа Decky в конкретной версии Steam UI, регистрация/handshake Cloudflare WARP и внешние провайдеры требуют проверки на устройстве. Шаги — docs/TESTING.md. Decky zip требует сервис из полного пакета.
