Helmsman 0.1.0-alpha.7 для Steam Deck.

- Исправлена огромная иконка пункта Decky: SVG ограничен 20×20, заголовок помещается в одну строку.
- На основном экране Game Mode оставлены состояние/ошибка, подключение, профиль, маршрут и обновление подписок. Редкие действия скрыты под «Дополнительно»; генератор WARP дополнительно сворачивается. Используются штатные элементы Decky для фокуса геймпада.
- Автоподключение при загрузке Steam Deck стало отдельной опцией, выключенной по умолчанию. Настройка доступна в Decky → Дополнительно и Desktop → Настройки, хранится в общей конфигурации сервиса. Переключатель сам по себе не запускает/останавливает/перезапускает VPN.
- При выключенной опции новая загрузка оставляет VPN отключённым. Включённая опция запускает выбранный профиль при следующей загрузке, независимо от последнего ручного отключения. Восстановление уже включённого соединения после сбоя службы, сна и смены сети сохраняется независимо от этой опции. Первое обновление старой установки сохраняет текущий сеанс и HWID.
- Исправлено восстановление отображения после временной недоступности сервиса; повторный выбор того же профиля/маршрута в Decky не отправляет команду переключения.
- Включены Desktop в духе M3 Expressive, нативный KDE Wayland и импорт Xray mux из alpha.6.

Обновление: распаковать helmsman-0.1.0-alpha.7-linux-x86_64.tar.gz, выполнить sudo bash install.sh --decky. Для загрузки новой панели может потребоваться закрыть и снова открыть Decky. Данные остаются в /opt/helmsman/state.

Проверки: тесты состояния/миграции/общего RPC, сборка плагина, GUI, реальные сетевые транспорты, TUN/DNS/UDP и crash guard, упакованный Wayland/X11 GUI, установка/обновление/удаление. Дополнительно в systemd проверяется имитация новой загрузки с обеими настройками автоподключения. Физический Steam Deck, реальный runtime Game Mode/фокус и аппаратная перезагрузка требуют приёмки на устройстве.
